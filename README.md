
# 🌟 Basic Calculator

A simple, colorful web-based calculator built using **HTML**, **CSS**, and **JavaScript**.  
It supports basic arithmetic operations with a vibrant UI placed over a Hyderabad-themed background.

## ✨ Features

- Clean, centered calculator layout on a full-page background image. :contentReference[oaicite:0]{index=0}  
- Basic operations: **addition (+)**, **subtraction (-)**, **multiplication (*)**, **division (/)**. :contentReference[oaicite:1]{index=1}  
- Functional buttons:
  - `AC` – clear everything  
  - `Del` – delete last character  
  - `.` – decimal input  
  - `00`, `0–9` – number input  
  - `=` – evaluate expression using JavaScript’s `eval()` function.   
- Hover effects on buttons for a more interactive feel. :contentReference[oaicite:3]{index=3}  

---

## 🛠️ Tech Stack

- **HTML5** – Calculator layout and button structure. :contentReference[oaicite:4]{index=4}  
- **CSS3** – Styling, colors, hover effects, and background image. :contentReference[oaicite:5]{index=5}  
- **JavaScript** – Inline button handlers to update the display and evaluate expressions.

## 🚀 Getting Started

1. **Clone or download** this repository.
2. Make sure the files stay in the **same folder** so the CSS and image paths work correctly.
3. Open `calculator(project).html` in any modern web browser.
4. Start clicking the buttons and do your calculations!

No additional setup, frameworks, or build tools are required.

---

## 📌 How to Use

* Click number buttons (`0–9`, `00`) to build your expression.
* Use `+ - * /` to choose the operation.
* Press `=` to calculate the result.
* Press `AC` to clear the entire display.
* Press `Del` to remove the last character.
